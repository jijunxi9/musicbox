# 音乐盒 · 58 首

一个纯网页 / PWA 的私人歌单播放器。手机上「添加到主屏幕」后跟原生音乐 App 一样用：锁屏控制、歌词、进度拖拽、离线下载。

## 它怎么放歌

- 每首歌在歌单里已经绑好了原唱的音源 ID（逐首核对过歌手与专辑，不是模糊搜索第一条）。
- 播放时向第三方解析接口（`music-api.gdstudio.xyz`）换取直链，接口返回的是带 CDN 签名的 mp3，任何地区都能直接播，不需要代理、不需要加速器。
- 直链过期（约几小时）后自动重新解析；解析失败会自动降码率重试 320 → 192 → 128。

## 在 iPhone 上用

1. Safari 打开部署好的地址（或电脑上 `node server.mjs` 后开局域网地址）。
2. 底部「分享」→ **添加到主屏幕**。
3. 从主屏幕图标进入（必须是这个入口，Safari 标签页里没有全屏和后台播放）。
4. 首次播放点一下封面/播放键（iOS 要求用户手势才能出声）。

## 离线：不需要网络、不需要加速器

播放页底部 **⤓ 离线** → 「下载全部」。58 首约 600MB，存在浏览器 IndexedDB 里：

- 下载完成后，飞行模式也能听，秒开、随便拖进度。
- 建议连 Wi-Fi 下，并且下载时别锁屏（iOS 会暂停后台下载）。
- 也可以只下当前这首，或在下完几首后随时补。

## 设置里能改

- 音质 128 / 192 / 320K（下一首生效）
- 看本机占用、一键清空缓存
- 定时关闭（10–90 分钟）

## 换源（某首解析失败时）

长按歌单里那一行 → 弹出搜索框 → 从结果里挑一条，立刻换源播放。改完的映射存在本机，不影响别人。

## 自己部署

静态托管随便放（GitHub Pages / Cloudflare Pages / Vercel / 自己的服务器），整个目录传上去即可，无需后端。本地预览：

```bash
node server.mjs 8787
```

> Service Worker（离线打开外壳）只在 `https://` 或 `localhost` 下注册；局域网 `http://192.168.x.x` 能听但不会有离线外壳。
